# Lush product catalogue

React catalogue backed by the existing Saleor GraphQL endpoint.

Run `npm ci`, then `npm start` (port 3003). Use `npm test` for a single test run,
`npm run test:watch` for watch mode, and `npm run build` to create `build/`.

See [development and security checks](DEVELOPMENT.md) for runtime requirements,
Vite configuration, deployment details, and dependency maintenance.
